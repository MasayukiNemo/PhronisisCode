# TETTRIS — ピンチをT1個でねじ伏せるテトリス

ボムで消さない。積みの言葉で救う。最汎用のTを「権利」として与えるテトリスです。

## 4つの新しさ

### 1. どこでもセーブ
Sで丸ごと保存、Lで何度でも再試行。10ラインごとに自動保存、Qで直前の区切りへ。手動と自動は別枠で潰し合わない。

### 2. ふたつの手持ち
HOLD(C): 1個入れ替え。T-POWER(F): ゲージ満タンで武装、再押下で現ミノをTに変身。HOLDにTがなくてもその場で作れる。毎手「HOLDかTかそのままか」の二択が生まれる。

### 3. ため方はリスクだけ
| 消去 | 加算 |
|---|---|
| 1-2ライン | +0 |
| 3ライン | +1 |
| 4ライン | +2 |
3点で満タン。Fで武装するとゲージ0・ストック1に。ストック中にFでT化。満タン放置で3/4を消すとバーストで0に戻る。ストック中も0から再チャージでき、ストック1+ゲージ3が最硬で1/2消し維持可。平地ではたまらない、欲張ると溢れる——その駆け引きが熱い。

### 4. 構える321カウント
LOAD(L/Q)・リスタート(R)は常に3→2→1、ポーズ解除(P)はLv3以上のみ3→2→1。カウント中は重力もロックも止まる。

## 操作
←→移動、↓ソフト、↑/X時計、Z反時計、Spaceハード、C HOLD、F 武装/発射（1回目武装・2回目発射）

## 遊び方
1. SPACEで開始 → 2. 3/4を狙い3点でF武装 → 3. ピンチでF発射 → 4. 練習はS/L、保険はQ

積む奴ほど壊れる。構える奴だけ生き残る。
