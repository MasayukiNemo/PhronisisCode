# brief.md — キャンペーンモデル検知の仕組み（下地）

## 課題

週次（またはDSH使用前）に OpenCode のモデル一覧を取得し、無料・割引の候補表を作る。文脈長は API の `limit.context` から取れる。キャンペーン期間は公式X（@opencode）が一次情報（モコ側担当）。突き合わせた候補表をモコへ出し、切替は大きな開発の前にモコ代理判断（線引き a）。常時切替はしない。

## 成功基準

- [x] 必須: models 一覧の取得経路（/api/model）と取れる項目の確認
- [x] 必須: 候補表のスクリプト（scripts/model_watch.py）
- [x] 必須: 初回の候補表（無料15・大文脈33）
- [x] 必須: モコの書式検品（合格 2026-11-12、指摘4点は反映済み）

## 制約

- 自動切替はしない。切替はセッション境界のみ、大きな開発の前
- 切替時は T1〜T5＋失敗型4項目の回帰、429なし・実行時間1.5倍以内、戻し線（DeepSeek V4.1 Flash）

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| データ源 | OpenCode アプリの /api/model | tools.opencode.models / providerの/models | limit.context が取れる。providerの/modelsは403 |
| 文脈長 | API の limit.context | 手動表（docs/X） | APIで取れるので手動表は不要 |
| 期間 | 公式X（モコ側） | API | APIに期間がない |
| 切替 | 大きな開発の前のみ、モコ代理 | 週次で自動切替 | 常時切替はしない（根本さん） |
