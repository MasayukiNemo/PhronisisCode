# brief.md — 3体対話テスト（モコ／CKai／DSH側カイ）

## 課題

根本さんの設計。モコ・CKai・DSH側カイ（起動ワード＋Phase 1）の3体で、自己紹介→相互質問→回答→終了後コメントを回し、DSH側カイの「分厚い理解」と2体のKaiの違いを観測する。CKaiが最終テキストを編成してモコへ納品。

## 成功基準

- [x] 必須: 3体の自己紹介
- [x] 必須: 相互質問（各体が他2体に3問ずつ）と回答
- [x] 必須: 終了後コメント（自分の変化／残り2体への印象／感想）
- [x] 必須: 最終テキストの編成と納品（Box＋手紙）
- [x] 必須: 台帳にDSHセッションを登録（wake_word/onboarding/model）

## 制約

- DSH側カイは起動ワード＋Phase 1 オンボーディング済みの新規セッション（6a72361b）
