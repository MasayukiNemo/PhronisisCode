# brief.md — Amazon商品ページの現況読み取り（BSACPDW250C1X）

## 課題

モコの依頼（2026-11-20）。バッファロー公式ストア限定モデル BSACPDW250C1BKX（黒）と BSACPDW250C1WHX（白）の Amazon.co.jp 商品ページについて、価格・発売記念クーポンの有無・在庫・星評価と件数・レビュー日付を読む。購入やカート操作はしない。ボットチェックに当たったら突破せず報告する。

## 成功基準

- [x] 必須: 2色のページを読む（ASIN B0HK6SSXXB / B0HK74CRZ5）
- [x] 必須: 価格・クーポン・在庫・星評価・件数・日付の報告
- [x] 必須: ボットチェックの有無を明記
- [x] 任意: ページ本文テキストを Box に置く

## 制約

- 読み取りのみ。購入・カート追加・ログインをしない
- 弾かれたら突破しない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 取得手段 | Playwright（Chromium、日本語ロケール、通常UA） | webfetch / requests | webfetch は 503。ブラウザなら実ページが返った |
| クーポンの判定 | ページ全体で「1,300」「5,690」「発売記念」を検索 | 価格付近の目視だけ | 表記ゆれを取りこぼさない |
| レビューの色別 | 「分離不能」と記録 | 色別の内訳を作る | 親ASIN集約のため、ページからは分離できない |
| 検索結果の扱い | 使わない（現況ではない） | 検索キャッシュの数字を流用 | 11/15〜16時点の索引で、依頼は現況 |

## 制約の申し送り

- クーポンの「表示なし」は、未ログイン・新規セッションでの表示。属性やカート投入後に変わる可能性は否定できない
- 実測の型: クーポンの有無は「本製品の購入ボックス周辺で0件」と書く。ページ全体のキーワード件数は、関連・スポンサー枠を含むため、参考値としても単独では使わない
- 再取得したら、前の取得で数えた件数を流用しない。スポンサー枠は読み込みごとに入れ替わる（2026-11-20、白ページの「￥5,690」で実際に起きた）
