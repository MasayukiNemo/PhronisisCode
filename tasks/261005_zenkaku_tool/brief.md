# brief.md — 全角半角変換ツール（1枚HTML）

## 課題

オフラインで動作する単一HTMLの全角半角変換ツールを作る。外部依存なしで英数記号・カタカナ・スペースの相互変換とプレビューを提供する。

## 前提条件

- [x] 単一HTMLファイル、外部CDN・外部JS/CSS依存なし、file:// オフラインで動作
- [x] UTF-8 で保存（hooks/utf8_check.py を通過すること）
- [x] 成果物はリポジトリ内に保存（例: tools/zenkaku-hankaku.html）

## 成功基準

- [ ] 必須1: 英数記号の全角→半角変換（Ａ-Ｚａ-ｚ０-９＋記号群）
- [ ] 必須2: 英数記号の半角→全角変換
- [ ] 必須3: カタカナの全角→半角変換（濁点・半濁点の結合文字対応）
- [ ] 必須4: カタカナの半角→全角変換
- [ ] 必須5: スペース変換（全角スペースU+3000⇔半角スペースU+0020、両方向。タブ・改行・NBSPは対象外で不変）
- [ ] 必須6: プレビュー表示（変換結果のリアルタイム表示＋入出力の文字数表示）
- [ ] 必須7: クリアボタン（入力・出力の一括消去）
- [ ] 必須8: 単一HTML・外部依存なし・オフライン動作
- [ ] 任意: コピーボタン、変換オプションの個別ON/OFF

## 制約

- 技術スタック: 素のHTML+CSS+JSのみ（1ファイル完結）
- 期限: なし（即時実施）
- 参照: なし

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 保存先 | tools/zenkaku-hankaku.html に新規作成 | 既存docs配下への混在 | 道具系はtools配下に分離する方が追従性が高い |
| カタカナ半角化の方式 | 対応表＋濁点結合（ガ→ｶﾞ方式） | Unicode NFKCのみ | NFKCは半角→全角方向にしか効かず、全角→半角は対応表が必要なため |
| 変換UI | 方向ボタン4種＋個別実行 | 双方向自動変換のみ | 誤変換防止と要件の明示性のため方向を明示 |
| Yuna/Hayato反映 | 範囲ガード付き演算・両方向濁点合成/分解・空白対象限定・クリアは入出力一括 | 曖昧なまま実装 | 英数記号は範囲外を不変にし、スペースはU+3000/U+0020のみ対象、クリアは入出力一括消去で確定 |
