# deep_thought.md — 深層思考（Kai）

## 本質

- サウンドの本質はフィードバック。落下で「置いた」、消去で「決まった」、満タンで「貯まった」、武装で「構えた」、使用で「放った」、バーストで「失った」を音で即時に知らせることで、視覚だけでは伝わらない手触りが生まれる
- 移動音やBGMを不要とした判断は正しい。テトリスの静謐さを保ちつつ、6点の節目だけを音で彩ることで、こぎみよさが最大化される
- 合成音の利点は軽量さと制御性。外部ファイルはfile://で失敗するが、OscillatorならAudioContextさえあればどこでも鳴る。周波数とエンベロープで感情を正確に設計できる

## 判断OS照合

- 思想的一貫性: テトリスの思想は「積むことの快感」。音は積む快感を増幅するもので、邪魔をしないことが一貫性に適う
- 本質的シンプルさ: 6音に絞ることで、音の役割が明確になる。何でも鳴らすより、節目だけ鳴らす方が伝わる
- 追従性: Oscillator 1個 + Gain 1個で1音を構成すれば、誰でも周波数と時間で音色を追える
- 実用均衡: Web Audioはモダンブラウザで広く対応。AudioContext生成をユーザ操作後に遅延することで、自動再生制限を回避しつつ実用性を担保する

## 確信度

- 高確信85%: 6音の対象（落下/消去/満タン/武装/使用/バースト）はユーザ要求通りで確定
- 中確信65%: 音色の具体的な周波数 — 120Hzのポンや440+880Hzの和音は経験則で決めたが、実機で聞いて微調整が必要
- 中確信60%: 音量0.12-0.18の控えめさ — テトリスの世界観には合うが、環境によっては小さすぎる可能性。ミュートトグルは任意に留める
