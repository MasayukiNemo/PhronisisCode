# brief.md — サウンド6点追加

## 課題

現行 `docs/tetris/index.html`（TETTRIS、グラディウス式T武装済み）に、ゲームの手触りを高めるサウンド6点を Web Audio API による合成音で追加する。移動音やBGMは不要とし、こぎみよい効果音のみに絞る。

## 前提条件

- [x] ベースは `docs/tetris/index.html` 1247行版（T-POWER 2段階武装済み、3列レイアウト、F/A武装）
- [x] 外部ファイルなし（file:// で CORS に引っかからないよう Oscillator 合成のみ）
- [x] 単一HTML / IIFE / Canvas 制約は維持

## 成功基準

- [x] 必須1: 落下音 — ピースが接地して固定された際（doLock時）に、低めのポン（例: 120Hz sine 80ms）が鳴ること
- [x] 必須2: 消去音 — ライン消去時にキラッと明るい和音が鳴ること。3ラインと4ラインで派手さを変える（3: 440+880Hz、4: 550+880+1100Hz の和音、各120ms）
- [x] 必須3: Tゲージ満タン音 — powerGaugeが3に到達した瞬間に、キュイッと上がるチャージ音（300→600Hz sweep 200ms）が鳴ること
- [x] 必須4: T武装音 — ゲージ3でF/Aを押してストックした際に、カシャッと武装音（800Hz square+ 1200Hz over tone 150ms）が鳴ること
- [x] 必須5: T使用音 — ストックからF/AでTに変換した際に、シュッと変身音（400→900Hz sweep 180ms + ノイズ的要素）が鳴ること
- [x] 必須6: Tバースト音 — ゲージ3で放置して3/4消しでバーストした際に、ブッと弾けるミス音（150Hz sawtooth 下降 300ms）が鳴ること
- [x] 必須7: 非干渉 — カウントダウン中、ポーズ中、ゲームオーバー中はサウンドが鳴らないこと。音量は控えめ（gain 0.12-0.18）で、複数同時発火時はクリップしないこと
- [x] 必須8: リグレッションなし — 既存のスコア/レベル/T-POWER/セーブ等が引き続きPASSし、行数は1250-1350行を目安とする
- [ ] 任意1: 消去時のライン数による音階差の微調整
- [ ] 任意2: ミュートトグル（Mキー）

## 制約

- 技術スタック: Web Audio API（AudioContext + Oscillator + Gain）のみ。外部mp3/wav不使用、ライブラリ不使用
- 配置: `docs/tetris/index.html` を上書き。AudioContextは初回ユーザ操作（keydown/click）で生成（ブラウザの自動再生制限対策）
- 行数: 1250-1350行を目安とする
- 品質: `scripts/code_health_check.py --no-color` 5/5 PASS 維持。try/catchで AudioContext 生成失敗時もクラッシュしない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 音源 | Oscillator合成 | 外部mp3/wav | file:// でCORSに引っかからず、単一HTMLで完結する。6音程度なら合成で十分こぎみよい |
| 対象 | 6点のみ（落下/消去/満タン/武装/使用/バースト） | 移動音/BGM含む | 要求通り移動音やBGMは不要とし、手触りに直結する6点に絞ることで世界観を壊さない |
| 音色 | 用途別に周波数と波形を分ける（sine/square/saw） | 全て同波形 | 低音は接地感、高音和音は爽快感、上昇sweepは期待感、下降sawは喪失感と、感情と周波数を対応させる |
| 音量 | 0.12-0.18の控えめ | 0.3以上の大きめ | テトリスの世界は静謐さが基調。控えめにすることでこぎみよさを保つ |
| 初回生成 | 初回keydown/clickでAudioContext生成 | 起動時に生成 | ブラウザの自動再生ポリシーで起動時生成はブロックされる。ユーザ操作後に生成することで確実に鳴る |
