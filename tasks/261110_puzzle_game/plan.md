# plan.md — 実装計画

## アーキテクチャ

単一HTMLファイル（`scripts/minesweeper.html`）。外部ライブラリ・通信なし。CSS/JS をインラインで同梱。

- 8x8 マス・10爆弾
- 初タップは必ず安全（爆弾は初タップ後に、そのマスと隣接マスを除いて配置）
- 0のマスを開くと連続展開（flood fill）
- 旗モードONでタップすると旗を立てる（目印）
- クリア: 爆弾以外のマスをすべて開いた
- ゲームオーバー: 爆弾を開いた
- リスタート: 画面上の「もう一度」
