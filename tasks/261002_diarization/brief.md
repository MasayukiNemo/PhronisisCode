# brief.md — タスク定義

## 課題

スマホ録音の打ち合わせ音声から、話者分離と意味補完つき文字起こしをゼロコスト近傍で実現する。単独アプリ化またはKaiが音声を受けて分離出力する運用も含め、アプローチ調査と既存OSSの利用可否を整理する。

## 前提条件

- [x] 入力はスマホ録音音声ファイル (Googleレコーダー由来m4a、30分から2時間、2名以上)
- [x] GPUなし、CPUのみローカル + Google Colab Proあり (既契約の範囲内で追加コストなし)
- [x] 中国語混じりあり、日本語化できるとベター (逐語の日本語訳まで含む)
- [ ] 現状は話者分離ができずKaiの認識が誤るという課題実感がある
- [ ] コストは追加ゼロであること (ローカル実行 + 既契約Colab Proの範囲内。都度課金APIは除外)
- [ ] Windows 11 + Python 3.13.5 + node環境で動作可能な範囲を優先
- [ ] 一から作らず既存OSSの利用・改造を優先

## 成功基準

- [ ] 必須: ゼロコスト近傍のアプローチを3案以上整理し、仕組み・精度・コスト・手間を比較したこと
- [ ] 必須: 既存OSS・ツールを5件以上挙げ、ライセンスと改造容易性を評価したこと
- [ ] 必須: 推奨の第一案と次点を選び、理由と次の実装手順を示したこと
- [ ] 任意: サンプル音声での試行結果 (今回は調査優先のため任意)

## 制約

- 技術スタック: Python中心、Colab Pro GPU本線・ローカルCPU従線、外部課金APIは使わない
- 期限: なし、調査速報を優先
- 参照: knowledge/code_knowledge/agy.md、Web検索、GitHub OSS

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 調査範囲 | ローカルOSS+無料枠+Kai運用の3系統で整理 | 課金API中心の比較 | コストゼロ要求に忠実なため |
| 比較軸 | 仕組み・精度・コスト・手間の4軸で比較 | 価格のみ比較 | Hayato指摘を受けて物差しを固定したため |
| 招集判断 | Hermesのみ招集、Yuna+Hayatoはトライアングルとして実施 | Gaia/Artemis/Daedalus/Metis/Athenaは呼ばない | 設計案競合なし・3ファイル変更なし・実装なし・統合不要のため。呼ばなかった理由をここに残す |
| 重さ対応 | sherpa-onnx先行疎通+faster-whisper精度比較の二段構え | whisperX一本に固定 | Yuna指摘のWindows重さとHayato指摘の動作制約目配りに対応するため |
| 新前提反映 | CPUのみ+Colab・2時間m4a・中日対応で再評価 | GPU前提のまま | GPUなし・長時間・翻訳要望が確定したため |
| 中日対応 | 起こしは原文のまま+Kaiで日本語化 | whisper translateで直接日本語化 | translateは英語行きのみ・turboはtranscribe専用のため |
| PoC実装 | 単一CLI+フォールバック継続+Colab流用手順 | フル機能一発実装 | 依存未導入・ffmpegなし環境で試行可能にするため |
| 品質ゲート | Metis3点反映後にHayatoゲートPASSでテスト入り | 未検証のまま試行 | 手続き検証を最終防衛線にするため |
| 速度対応 | 全文ローカル中止+Colab Pro GPU本線、CPU側はバッチ追加 | 遅いまま回し続ける | RTF0.77で実用外と実測したため。使えない手段に固執しない |
| コスト定義 | Colab Proは既契約範囲で追加ゼロと明記 | 無料枠のまま | Pro所持が確定し限界費用ゼロのため。都度課金は引き続き除外 |
| 効果整理 | whisperの取り分は時刻・話者・突合せ材料と確定 | Pixel単独で十分 | Pixelに時刻話者がなく誤り検出もできないため。議事録用途では統合が正解 |
| poc2前提 | 判定保留、小規模な偽装可能性実験でのみ継続 | 無条件推進か即殺し | YunaHayato一致で前提脆弱のため。5分検証で時刻一致を見て存廃決定 |
| poc2存廃 | 廃案。v2継続 | アライメント採用 | 5分実測でalignが起こしの4倍遅いため。速さの根拠崩壊 |
