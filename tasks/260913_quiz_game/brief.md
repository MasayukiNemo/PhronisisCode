# brief.md — Geminiおまかせクイズゲーム（CLI対話式）

## 課題

agy経由Geminiにテーマ・出題・解説を任せるCLIクイズゲームを作る。遊びながら今回のagy実装を実地テストする

## 前提条件

- [ ] 要件: おまかせ出題、生成＋解説、CLI対話式（根本さん回答済み）
- [ ] conduct準拠: 使うタスクでask前にquota確認、7%以下は停止、ask結果はlogに記録
- [ ] 追加依存なし（標準ライブラリのみ）

## 成功基準

- [ ] 必須: `python scripts/quiz_game.py` が対話開始しN問出題する
- [ ] 必須: Gemini生成の問題・選択肢・解説が表示される
- [ ] 必須: 正誤判定と最終スコアが表示される
- [ ] 必須: agy不調時は明示エラーで終了する（黙って落ちない）
- [ ] 必須: ask前にquota確認し7%以下では開始しない

## 制約

- 技術スタック: Python 3.x標準ライブラリのみ
- Windows cp932コンソールで落ちないこと
- 出力先はリポジトリ内（scripts/quiz_game.py配置）

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 出題方式 | 1askで5問まとめ取り | 1問1ask | quota節約・待ち時間短縮。おまかせ出題と相性良し |
| 応答形式 | strict JSON＋失敗時明示エラー | リトライ無限・推測補完 | 誤解析の捏造を避ける。失敗は失敗と言う |
| 失敗時 | リトライ1回＋使える問だけ救済 | 即死終了 | Yuna/Hayato指摘。全滅は冷たい。捏造せず救済する |
| テーマ | 起動時に1行選択（空=おまかせ） | 完全おまかせ固定 | 驚きは残しつつ遊びの軸を根本さんが握れる |
| 入力 | 範囲外・空は再入力ループ | 素通し | ガバ判定にしない |
