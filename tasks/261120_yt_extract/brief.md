# brief.md — 英語YouTube動画の字幕抽出（AI harness crash course）

## 課題

モコの依頼（2026-11-20）。https://youtu.be/2C_CefSQEAQ（英語）の字幕を取得し、タイムスタンプ無しの平文にして Box の `moko-code/yt-extract-20261120/` に置く。要約・翻訳はモコ側。取得は CKai 側（モコ側VMはYouTubeに弾かれやすい）。

## 成功基準

- [x] 必須: 字幕の取得（手動優先、無ければ自動の英語）
- [x] 必須: 平文への整形（要約・改変なし）
- [x] 必須: メタデータ（タイトル・チャンネル・公開日・長さ・字幕種別と言語）の報告
- [x] 必須: テキストと元 vtt を Box の指定フォルダへ
- [x] 必須: 取得できない場合の文面報告（今回は該当なし）

## 制約

- 単発。恒常ジョブ化しない
- 翻訳・要約はしない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 字幕の種類 | 手動 en-US | 自動 en-orig | 手動があれば優先、という依頼条件 |
| 変換 | vtt_to_text.py を拡張（mode/lang） | 既存のまま力技で整形 | 既存は日本語自動字幕専用。英語手動では語間が詰まる |
| 自動／手動の判定 | インライン時刻タグの有無 | 行の重なり方 | 実測で前者が確実。後者で誤判定した |
| 既存成果物への影響 | バッファロー分を再変換して一致確認 | 目視のみ | 変換器を変えたので回帰を実測で押さえる |
