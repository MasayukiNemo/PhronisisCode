# brief.md — 検体9号（ぶせな式）Stage 2 フル再現の分担

## 課題

モコのトレード研究所、検体9号（ぶせな式＝20EMAエンベロープのゾーン別逆張りスキャルピング）の Stage 2（状態機械つきフル再現）を、EURUSD / USDJPY の M1 全期間（2019-01-01〜2026-11-13）で実行する。凍結仕様（2026-11-16、D1–D16）とランナーはモコ側と同一物。計算ロジックは変更しない。

Stage 1（ゾーン到達イベント集計＝中心主張の検証）はモコ側で完了済み、判定は「未証明・要経過観察」。Stage 2 はその結果にかかわらず回す（D16）。

- [x] 必須: パッケージ取得とハッシュ確認（zip・スクリプト・データ2つ）
- [x] 必須: 凍結コマンドを1回実行（--max-bars / --out-dir を付けない）
- [x] 必須: 4ファイル（stage2_results.json、trades_EURUSD.csv、trades_USDJPY.csv、stage2_run.log）の生成

- [x] 必須: ログとCSVの件数整合の確認

## 制約

- スクリプトと凍結条件を変更しない。
- 結果の地位: ティック手法の M1 近似版であり、裁量の原典そのものではない。
