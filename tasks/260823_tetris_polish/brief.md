# brief.md — オートセーブ + 321カウントダウン拡張

## 課題

現行 `docs/tetris/index.html`（セーブ/ロード+ガイドライン版）に、長時間プレイを支える2機能を追加する。1) オートセーブで手動Sを忘れても復帰できること、2) 高速域でのリスタート時に321カウントダウンで構えられること。

## 前提条件

- [x] ベースは `docs/tetris/index.html` 1116行版（Space開始/ソフトドロップリピート/セーブ/ロード済み）
- [x] 既存の必須7点（セーブ/ロード/永続/破損分岐等）およびガイドライン8点を後退させない
- [x] 単一HTML / file:// / localStorage 制約は維持

## 成功基準

- [x] 必須1: オートセーブ — 10ライン消化（レベルアップ）毎に自動で `phronisis_tetris_auto_v1`（手動Sとは別キー）へ自動保存が走り、「AUTO SAVED」フラッシュ（1.5秒、水色）が表示される。手動Sの `phronisis_tetris_save_v1` は上書きせず、手動の練習局面を保護する
- [x] 必須2: オートセーブの非干渉 — ゲームオーバー中やポーズ中、未開始時、カウントダウン中はオートセーブが発火しないこと。AUTO SAVEDとカウントダウンが同時発生した場合はカウント終了までAUTO SAVEDを抑制（キュー）する
- [x] 必須3: 321カウントダウン — 以下の再開時に、盤面中央に 3 → 2 → 1（各600ms、計1.8秒、盤面は表示されたまま操作無効）のカウントダウン演出後に落下が再開すること
  - a) LOAD（L）で復元した直後 — 復元直後のレベルに関わらず常時（手動/AUTOいずれのロードでも）
  - b) Rでリスタートした直後 — 常時（レベル1でも構えが必要なため）
  - c) Pでポーズ解除した際、解除時点のレベル>=3（getDropInterval(level)<=680ms）の高速域でのみ。レベル1-2では即再開でよい。判定は解除時点のlevelで行う
- [x] 必須4: カウントダウン中の完全停止 — カウントダウン中（isCountdown=true）は以下をすべて停止すること: 重力(dropCounter進行)、ロックディレイ(lockTime進行)、DAS/ARRタイマー、ソフトドロップリピート、入力（移動/回転/ドロップ/HOLD）。カウント終了で lastTime=performance.now()、lockTime=0 にリセットして再開すること
- [x] 必須5: UI完全性 — AUTO SAVEDの色は通常SAVED（緑）と区別（例: 水色）、カウントダウンは save-flash とは別要素 #countdown で中央に大きく表示（48px）すること
- [x] 必須6: リグレッションなし — 手動S/L、Space開始、ソフトドロップリピート、DAS/ARR/HOLD/T-Spin等が引き続きPASSし、行数は1200-1300行を目安とする
- [ ] 任意1: オートセーブのトグル（Aキーで ON/OFF）
- [ ] 任意2: カウントダウン中の BGM/効果音（今回は不採用）

## 制約

- 技術スタック: 単一HTML / IIFE / Canvas 2D / localStorage のみ。外部ライブラリ不使用
- 配置: `docs/tetris/index.html` を上書き
- 行数: 1200-1300行を目安とし、セクション見出しで可読性を保つ
- 品質: `scripts/code_health_check.py --no-color` 5/5 PASS 維持

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| オートセーブ間隔 | 10ライン（レベルアップ）毎 | 毎ピース/毎秒 | 毎ピースは頻繁すぎてフラッシュが邪魔、毎秒はラインと無関係。10ラインは既存のレベル区切りと一致し自然で、保存頻度と視認性の均衡が良い |
| オートセーブキー | 別キー `phronisis_tetris_auto_v1`（手動は `phronisis_tetris_save_v1` を保護） | 同一キー上書き | 同一キーでは手動の練習局面が10ライン毎に消え「延々と」が一発撮りになる。別キーに分離し、Lは手動優先・手動がなければAUTOをロードするフォールバックで両立する |
| カウントダウン対象 | LOAD/Rは常時、ポーズ解除は解除時点Lv>=3のみ | 全再開で常時 | 常時だと低速域でテンポが悪くなる。高速域でのみ構えが必要という要求に忠実に、ポーズ解除は条件付きにした。判定は解除時点のlevel（getDropInterval判定）でチラつきを防ぐ |
| カウント中の停止 | 重力/ロック/DAS/ARR/ソフトドロップ/入力すべて停止、終了時にlastTime/lockTimeリセット | 重力のみ停止 | フラグ1つで重力だけ止めてもDASが裏でチャージされ1.8秒後に瞬間移動、lockTimeも溜まり即固定死する。停止対象を全列挙し、終了時にタイマーをリセットして再開する |
| カウント間隔 | 600ms×3（計1.8秒） | 1000ms×3（計3秒） | 3秒は長すぎてテンポを崩す。600msは視認しつつリズム良く構えられる |
| 表示要素 | 専用 #countdown（48px、中央） + 同時フラッシュ抑制 | save-flash流用 | save-flashはSAVED/ERROR用で役割が異なる。カウントダウンは盤面中央に大きく出すため専用要素で分離し、カウント中はAUTO SAVEDフラッシュを抑制（キュー）して視覚衝突を避ける |
| カウント中の入力 | isCountdownフラグで全停止（上記） | 入力はキュー | 準備中に誤って回転がキューされると意味がない。カウント中は完全停止する |
