# brief.md — 1枚HTMLのMarkdown表整形ツール

## 課題

区切りテキスト(CSV/TSV/任意区切り)をMarkdown表に変換する単一HTMLツールを作る。オフラインで開いてすぐ使えること。

## 前提条件

- [x] 同期: git fetch origin済み、origin/masterと差分なし、working tree clean。text-markdownは追跡なしworktree運用のためpull不要と判断
- [x] 配置: 成果物は docs/markdown-table/index.html 単一ファイル
- [x] 既存流儀: docs/tetris/index.html が単一HTML前例。file://直開き対応を継承

## 成功基準

- [ ] 必須: 単一HTML・外部依存なし・オフライン(file://)で動作する
- [ ] 必須: 区切りテキスト入力をMarkdown表テキストに変換して表示する
- [ ] 必須: 区切り文字を選択できる(CSV/TSV/任意の1文字)
- [ ] 必須: ヘッダ行の有無を切り替えできる
- [ ] 必須: クリアボタンで入力と出力を消せる
- [ ] 必須: python scripts/code_health_check.py --no-color が exit 0
- [ ] 任意: コピーボタンとプレビュー表示(使う現場の手間を減らす)

## 制約

- 技術スタック: HTML+CSS+JSのみ、CDN・外部フォント・fetch不使用
- 文字コード: UTF-8。Edit/Writeツールで編集しPowerShellのSet-Contentを使わない
- 出力先はリポジトリ内のみ(docs/markdown-table/index.html + tasks/261005_markdown_table/記録3点)

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 配置 | docs/markdown-table/index.html | tasks配下・リポジトリ外 | docs/tetris前例に合わせfile://配布を単純化。記録はtasksに残す |
| 区切り指定 | 自動判定+プリセット(カンマ/タブ/パイプ/セミコロン)+任意1文字 | プリセット固定・複数文字区切り | 要件の任意区切りを満たしつつ現場の貼付けミスを吸収。複数文字は仕様を肥大化させるので捨てる |
| CSV引用符 | カンマ時のみRFC4180風(" "...""対応) | 全区切りで引用符処理・素朴splitのみ | カンマ貼付けの実害(カンマ入りセル破壊)を最小機構で防ぐ。他区切りまで広げると複雑さが見合わない |
| 6神招集 | 招集なし | Gaia/Artemis等の招集 | 単一HTML・依存なし・調査不要。招集基準のいずれにも該当しないため呼ばなかった理由を残す |
| 追加機能 | コピー・プレビュー・行列数表示のみ | 高度整形(列幅揃え/ソート等) | 要件外の肥大化を避ける。コピーは出力物の持ち出しに直結する最小実用分のみ |
| ヘッダなし時 | 空ヘッダ行+セパレータで全行ボディ化 | 汎用見出し(列1...)自動生成・先頭行ヘッダ化 | Yuna照合。汎用見出しは捏造が残り削除手間が出る。空ヘッダは有効な表を保ちつつ誠実 |
| 引用符処理 | 全区切りで二重引用符対応 | カンマ限定 | Yuna/Hayato指摘。同一パーサを区切り引数化するだけでコスト増なし。囲み残りを防ぐ |
| 自動vs明示 | 明示選択が常に勝つ。自動は自動選択時のみ | 両立のまま | Hayato刺突。優先順位を仕様化して矛盾を潰す |
| 列数不揃い | 最大列数に空セル補完で正規化 | 未定義・過剰切捨て | Hayato刺突。有効な表を常に保証。過剰も潰さず残す |
| プレビュー | textContent/DOM構築のみ。innerHTML不使用 | innerHTML描画 | Hayato刺突。file://でもXSSしうるためエスケープ機構で潰す |
| 列幅揃え | パディング整形を任意チェック(既定off)で追加 | 捨てる | Yuna仮説3。東アジア幅考慮の簡易実装で可読性需要に応える。既定offで要件の素朴出力を保つ |
