# brief.md — 1枚HTML文字数カウンタ

## 課題

テキスト入力に対し文字数・行数・内外訳をリアルタイム表示する単一HTMLツールを作る。オフラインで直開きできる配布容易性を目指す。

## 前提条件

- [x] 単一HTML・外部依存なし（CDN・フォント・JSライブラリ不使用）・オフライン動作
- [x] ブラウザで file:// 直開きできること
- [x] リポジトリ内のみに出力すること

## 成功基準

- [x] 必須1: テキスト入力欄があり入力ごとにリアルタイム集計表示される
- [x] 必須2: 文字数（改行含む）と文字数（改行含まない）が表示される
- [x] 必須3: 行数が表示される
- [x] 必須4: 空白除外文字数（空白・改行を除く）が表示される
- [x] 必須5: 全角・半角の内訳が表示される
- [x] 必須6: クリアボタンで入力と集計がリセットされる
- [x] 必須7: 単一HTML（CSS/JS内包）で外部参照がない
- [ ] 任意1: 文字数コピーや目安表示などの補助機能

## 制約

- 技術スタック: HTML5 + CSS + Vanilla JavaScript。フレームワーク・ビルド不使用。単一HTMLを正とする
- 配置: `tasks/261005_char_counter/index.html`
- 品質: UTF-8、file:// 直開きで動作、`scripts/code_health_check.py --no-color` が exit 0（該当する場合）
- 定義: 改行は \r\n|\r|\n を各1文字として数える（textareaはブラウザがLF正規化するため実質\n単位。ロジックはCRLF耐性あり）。空白除外は正規表現 \s（半角空白・タブ・改行・全角空白U+3000含む）を除く。全角は U+0080以上のコードポイント（半角カナU+FF61-U+FF9Fは半角に補正）、半角はそれ以外。絵文字等はコードポイント数（書記素単位ではない）である旨を画面注記する。行数は空文字→0、それ以外→改行分割数（末尾改行は空行として加算しない方針ではなく分割数通りとする旨を注記）
