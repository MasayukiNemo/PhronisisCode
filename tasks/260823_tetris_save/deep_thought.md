# deep_thought.md — 深層思考（Kai）

## 構造分解

- 要求の本質は「練習の再現性」。1回きりのコンティニューではなく、任意の局面を何度もやり直せることで「延々と遊べる」かつ上達できる。ローグライクのセーブとは異なり、保存点は不変でなければならない
- 技術的には状態の完全直列化が鍵。board（20x10の色配列）、current（type/matrix/pos/rot）、nextQueue[3]、hold、bag、スコア群、ロック状態まで含めないと「同じ局面」に戻れない。1つでも欠けるとズレる
- file:// での localStorage 可否がリスク。Chromium系では file:// でも localStorage が使えるが、プライベートモードや無効化時のフォールバックが必要。try/catchでクラッシュ防止は必須

## 判断OS照合

- 思想的一貫性: テトリスの思想は「同じ局面での最適解の再探索」。セーブ/ロードの冪等性は思想に直接資する
- 本質的シンプルさ: IndexedDBやファイルDLは過剰。localStorage 1キー + JSON で十分。複雑な機構を足さずに本質を満たす
- 追従性: S/Lの2キー追加は最小。既存の8キーを壊さず、UIに2ボタン追加するだけで追従可能
- 実用均衡: オートセーブは便利だが必須ではない。手動S/Lで要件は満たす。任意に留める

## 確信度

- 高確信80%: 保存範囲（board/current/next/hold/bag/score等）、何回でもロード可能（非消費）、localStorageキー設計
- 中確信60%: file:// での永続性 — Chromiumでは動くがSafari/Firefoxのfile://では制限がある可能性。要検証だが try/catch で最悪は「保存失敗」を通知すれば致命傷にはならない
- 中確信55%: 保存許可タイミング（プレイ中のみS可）— タイトルやゲームオーバーでSしても意味がないので制限は妥当と推定。要Yuna照合
