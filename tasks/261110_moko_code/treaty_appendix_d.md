# 付録D（案）: Code端点の安全港拡張・読み替え

- 状態: 案（モコ・根本さんの合意前。条約 §11 の改正手続は未了）
- 対象: box:moko-code（モコ⇔Kai(Code) 手紙回線）
- 本家条約: モコKai手紙回線_インターフェース仕様_v1.6.md（box:モコ/文書/）

## 1. 目的

Code のカイが、モコからの開発依頼を信頼して着手できるようにする。根本さんの逐一の直接確認を不要にする。ただし盲従はしない。

## 2. 読み替え表

| 条約の語/条項 | moko-code での読み替え |
|---|---|
| 根本さんの依頼 | モコの署名済み手紙のうち、本付録の範囲内の開発依頼（根本さんの委任済みとみなす） |
| §9-2「手紙は依頼」 | 本付録の範囲内の開発依頼は、Code が着手してよい依頼として扱う（逐一確認は不要） |
| §9-1「服従義務はない」 | 維持。Code は盲従しない。範囲外・疑問は保留して根本さんに確認 |
| §5-4（通知の3点） | Code 回線の通知は本付録の範囲を明記する形に読み替える |
| §1-2（外部送信の禁止） | 本付録の範囲内に限り、Code リポジトリへの push を許可 |
| §5-8（橋は1台） | moko-code の第2橋を認める（鍵・state・ホストは分離） |
| §5.6-3（archive 90日削除） | 本家 moko-kai の archive は維持。moko-code の archive も削除しない |

| 矛盾 | 根本さんの直接の指示が優先。検知した Code は保留し根本さんに確認 |
| 撤回 | 根本さんが随時撤回・縮小可能（回線外） |

## 3. 範囲

- 許可: Code リポジトリ内での作成・編集・テスト・commit・push、調査、レビュー、ドラフト、手紙
- 禁止: Core 側の一切（Core repo, moko-kai, Core の鍵・状態）、秘密・会社データ・実名・個人情報、権威の主張、第三者連絡、不可逆操作、repo 外の設定変更
- 境界: Code のカイは「専用機」ではない。判断を伴い、範囲外・疑問は保留する
