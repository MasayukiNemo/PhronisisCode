# brief.md — yt-dlp 実地テスト（検体19号・ちりつも氏のチャンネル）

## 課題

モコの依頼（2026-11-18）。YouTube「FX研究家 ちりつも」（@fx_trader_tiritumo）に対して yt-dlp を実地に回し、モコ側の共有VMでは測れない項目を実測する。

1. チャンネル全動画の列挙（100本の壁を越えられるか、総数を確定できるか）
2. 各動画のメタデータ（公開日・タイトル・概要欄）が一括で取れるか
3. 字幕（自動生成含む）が取れるか、形式は何か
4. ブロック・制限に当たった場合の文面

試験であり、恒常的な収集ジョブ化はしない。道具の導入可否は根本さんが判断する。

## 成功基準

- [x] 必須: フラット列挙の本数と期間
- [x] 必須: メタデータの取得可否（公開日・タイトル・概要欄）
- [x] 必須: 字幕の取得可否と形式
- [x] 必須: つまずいた点（警告・制限の文面）
- [ ] 必須: 素材の置き場所をモコへ連絡

## 制約

- 試験のみ。定期ジョブ化しない。
- 取得物は素材として Box に置き、置き場所を返信に書く。
- 礼儀として取得間隔を空ける（--sleep-requests 0.5）。

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 導入方法 | 専用 venv に pip で yt-dlp | グローバル導入・バイナリ配置 | 検証用に閉じる。後で捨てられる |
| 列挙 | --flat-playlist で全件 | RSS（15件まで） | 総数の確定が目的 |
| タイトル | 本抽出（--skip-download）で取り直す | フラット列挙のタイトル | フラットは翻訳・切り詰めされる（実測） |
| 字幕 | 自動字幕 ja-orig を VTT で取得 | 音声→Whisper | まず既存の字幕で足りるかを見る |
