# brief.md — マインスイーパv2（お助け探知機の追加）

## 課題

モコの開発依頼（付録D第2回）。納品済みのマインスイーパに「お助け探知機」を追加し、`minesweeper_v2.html` として納品。v1は残す。

## 受け入れ基準（モコ指定）

1. 既存仕様をすべて維持（8x8・爆弾10・初タップ安全・旗モード・タイマー・クリア/ゲームオーバー判定・リスタート・遊び方の画面内表示・単一HTML・外部依存なし・スマホ縦画面）
2. 探知機ボタン（または同等のUI）を置き、残り回数（1回）が分かること
3. 探知機を押すとスキャンモードになり、次にタップした未開放マスについて、地雷の有無だけを表示。そのマスは開けない。旗の状態も変えない。タイマーは止めない
4. 結果の表示は、地雷あり／なしが一目で分かる形。表示の保持方法（残す／一時的）は任せるが、その後の「開ける」「旗」操作を妨げない
5. スキャン後はスキャンモードを終了し、残り回数は0になって、ボタンは使えなくなる
6. 盤面が生成される前（最初のマスを開ける前）はスキャンできない（ボタンを無効にするか、押しても消費しない）
7. スキャンはクリア判定に影響しない（スキャンしたマスは「開けた」ことに数えない）
8. リスタートすると、探知機も1回に復活

## 成功基準

- [x] 必須: 上記8項目をすべて満たす
- [x] 必須: 単一HTML・外部依存なし
- [x] 必須: `minesweeper_v2.html` を Box moko-code に納品し手紙で通知
- [x] 必須: v1（`minesweeper.html`）を残す
- [x] 必須: Yuna（仕様曖昧さ）・Metis（UI一見性）のチェックを経る

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 探知機の結果表示 | セル上の一時的バッジ（数秒で消える）＋メッセージバー | 永続表示 | 後の「開ける」「旗」操作を妨げない（基準4） |
| 生成前のスキャン | ボタンを無効化 | 押しても消費しない | 基準6。無効化の方が一見で分かる |
| スキャン中の無効タップ | スキャンをキャンセル（消費しない） | 無視 | 誤タップで消費しない。操作を取り消せる |
