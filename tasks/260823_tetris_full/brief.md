# brief.md — テトリス ガイドライン準拠拡張

## 課題

既存 `docs/tetris/index.html` の「テトリスに似た」実装を、公式ガイドラインに近い「まんま」へ作り込む。フロニシスの実装テストとして、SRS/ホールド/逆回転等の本質機構を漏れなく再現しつつプロダクト品質を維持する。

## 前提条件

- [x] ベースは `tasks/260823_tetris` の成果物（docs/tetris/index.html）を拡張する。新規作り直しではない
- [x] 既存の必須8点は後退させない（リグレッションなし）
- [x] 単一HTML / file:// 直開き / Vanilla Canvas の制約は維持

## 成功基準

- [x] 必須1: SRS完全対応 — JLSTZ/I/Oそれぞれの5パターン壁キック（Tetris Wiki準拠。下記「SRS定義」参照）で回転が壁際でも正しく決まる。時計回り（↑またはX）と反時計回り（Z）の両方が機能する
- [x] 必須2: ホールド — Cキーで1回/1ピースのホールド・スワップが機能し、HOLD表示（80x80 canvas）に保持ミノが描画される。ホールド後の再ホールドは接地/次ピースまで不可。Shiftは修飾キー衝突のため不採用（Cのみを正とする）
- [x] 必須3: ロックディレイ — 接地後500msの猶予。移動/回転成功でタイマーをリセットし最終リセットから500msで固定。ただしリセットは最大15回まで。以後は延長せず500msで強制固定（無限粘り防止）
- [x] 必須4: 7-BAG + NEXT拡張 — 7-BAGシャッフルを維持し、NEXTを3個表示（縦積み、各64x64 canvas相当、1個目を強調）に拡張する
- [x] 必須5: DAS/ARR — 左右長押しでDAS 150ms後にARR 30msで連続移動する（押しっぱなしでの操作性がガイドライン並みになる）
- [x] 必須6: スコア/レベル拡張 — 従来の100/300/500/800にレベル補正（×level）を追加し、T-Spin Mini/Regular の検出と加算（T-Spin 400/800、T-Spin Single 800等、簡易で可）を行う
- [x] 必須7: 操作体系の完全化 — ←→移動、↓ソフトドロップ、↑/X 時計回り、Z 反時計回り、Space ハードドロップ、C ホールド、P ポーズ、R リスタートがすべて機能し、キー説明がUIに反映される（Shiftは不採用）
- [x] 必須8: 既存8点のリグレッションなし — 10x20、ランダム落下、ライン消去、ゴースト、速度テーブル、file://動作が引き続きPASSする
- [x] 任意1: T-Spin表示演出（TSPIN! テキスト）
- [ ] 任意2: パーフェクトクリア検出

## 制約

- 配置: `docs/tetris/index.html` を上書き拡張（後方互換を保ちつつ1ファイルで完結）
- キー競合: 既存のカーソル+Spaceは維持しつつ、Z/X/Cを追加（Shiftは修飾キーで単押し発火が不安定かつブラウザ挙動と衝突するため不採用）。Arrow/Space/Z/X/Cは keydown で preventDefault、Shiftは対象外
- 行数上限: 単一HTMLで900〜1100行を目安とし、超過時はセクションコメントで可読性を担保（code_health維持のため肥大化を監視）

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| SRSの粒度 | フルSRS（JLSTZ 5試行/I 5試行/Oは回転なし） | 簡易2パターン維持 | 「まんま」要求のため簡易では不足。Tetris Wikiの kick table を正確に移植するコストは払う価値あり |
| 回転キー | ↑/XでCW、ZでCCW | ↑のみCW維持 | 両回転はガイドライン必須。↑は既存互換で残しつつX/Zで明確に分離。Spaceはハードドロップのまま |
| ホールド | Cのみ、1ピース1回制限 | ホールドなし | ガイドラインの中核。Shiftは修飾キー衝突で不採用。1回制限で無限ループ防止 |
| ロックディレイ | 500ms + 15回リセット上限 | 即時固定維持 | 猶予なしではガイドラインの操作感が出ない。15回上限で無限粘りを防止 |
| NEXT数 | 3個表示 | 1個維持 / 5個 | 1個では先読み不足、5個は画面占有が大きい。3個で実用と視認性の均衡 |
| DAS/ARR | DAS 150ms / ARR 30ms | 長押しで1回のみ | 長押し連続移動はガイドラインの操作性に直結。150/30は標準的で実装も簡潔 |
| スコア | レベル補正 + T-Spin簡易（T-Spin Single 800×Lv / Double 1200×Lv / Triple 1600×Lv に簡素化） | 固定100/300等維持 | 「まんま」ならレベル×とT-Spinは必須。完全なガイドライン点数表は過剰なので簡易3段階に留める |
| 行数肥大 | 900-1100行目安+セクション見出し | 無制限単一HTML | 1ファイル3000行化を防ぐため上限を明示。可読性はコメントと関数分離で担保 |

## SRS定義（Tetris Wiki準拠・実装で使用する値）

JLSTZ（T/S/Z/J/L）の kick table（CW: 0→1, 1→2, 2→3, 3→0 と CCW: 0→3, 3→2, 2→1, 1→0 で共用、5試行）:
- 0→1(CW): [(0,0), (-1,0), (-1,1), (0,-2), (-1,-2)]
- 1→0(CCW): [(0,0), (1,0), (1,-1), (0,2), (1,2)]
- 1→2: [(0,0), (1,0), (1,-1), (0,2), (1,2)]
- 2→1: [(0,0), (-1,0), (-1,1), (0,-2), (-1,-2)]
- 2→3: [(0,0), (1,0), (1,1), (0,-2), (1,-2)]
- 3→2: [(0,0), (-1,0), (-1,-1), (0,2), (-1,2)]
- 3→0: [(0,0), (-1,0), (-1,-1), (0,2), (-1,2)]
- 0→3: [(0,0), (1,0), (1,1), (0,-2), (1,-2)]

Iミノ専用（5試行）:
- 0→1: [(0,0), (-2,0), (1,0), (-2,-1), (1,2)]
- 1→0: [(0,0), (2,0), (-1,0), (2,1), (-1,-2)]
- 1→2: [(0,0), (-1,0), (2,0), (-1,2), (2,-1)]
- 2→1: [(0,0), (1,0), (-2,0), (1,-2), (-2,1)]
- 2→3: [(0,0), (2,0), (-1,0), (2,1), (-1,-2)]
- 3→2: [(0,0), (-2,0), (1,0), (-2,-1), (1,2)]
- 3→0: [(0,0), (1,0), (-2,0), (1,-2), (-2,1)]
- 0→3: [(0,0), (-1,0), (2,0), (-1,2), (2,-1)]

Oミノ: 回転なし（kick不要）

## NEXT/HOLDレイアウト定義

- HOLD: side上部に80x80 canvas #hold、保持なし時は空表示
- NEXT: HOLD直下に縦積み3個、各64x64相当を1canvas（#next 96x200）に縦3段で描画。1個目を強調（明度100%）、2/3個目は60%透過で先読み感を表現
- いずれも file:// で描画可能なCanvas 2Dのみで実装
