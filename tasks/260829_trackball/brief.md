# brief.md — タスク定義

## 課題

Mac (macOS Tahoe含む) でBluetooth接続の5ボタントラックボール（チルト対応高速慣性ホイール搭載モデル）の進む/戻るボタン、ホイールチルト左右、ホイール中央押し込みをキーカスタマイズ（複数キー対応 Cmd+C等）できる常駐アプリを作る。加えてカーソル速度を一時的に落とす精密操作モード（トグル/ホールド両対応、移動量スケール可変）を提供する。

## 前提条件

- [x] 対象デバイス: BUFFALO BSTBB700（新型・未発売、根本さん企画）。Bluetooth接続、5ボタン+チルト対応高速慣性ホイール。1台専用でMVP、VID/PIDはDiscoveryログで特定しフィルタ切替可能に退避
- [x] macOS 13 Ventura以降、Apple Silicon / Intel Universal、Tahoe対応
- [x] アクセシビリティ/入力監視権限の付与が前提（CGEventTap / IOHIDManager 利用）
- [x] 進む/戻るは現在macOSでキーボードエミュレーション（Cmd+[ / Cmd+] 相当）として動作中 → 方針確定: 未割り当ては素通しでブラウザ維持、割り当て時は横取りして再送抑止。うまくいかなければ再検討
- [x] 実機あり、Bluetooth接続可能。DiscoveryログモードでButton/Consumer/Keyboardのどれで届くかを実機確認する

## 成功基準

- [ ] 必須1: 進むボタン / 戻るボタン / ホイールチルト左 / チルト右 / ホイール中央押し込み の5入力それぞれに任意のキーコンボ（例 Cmd+C, Cmd+Shift+T, F13等）を割り当て可能。チルト/中央はキーコンボのみ（将来拡張で水平スクロール等を追加可能な構造）
- [ ] 必須2: 複数キー対応（修飾キー Cmd/Opt/Ctrl/Shift + 任意キー）のエミュレーションがグローバルに動作（CGEventPost）
- [ ] 必須3: カーソル精密モード — モード選択式でトグル（押すたびON/OFF）かホールド（押している間のみ減速）のどちらかを設定可能。トリガーはキーボードの未使用キー（例 F13/CapsLock）またはマウス側（進むボタン/チルト右）から1つを選択。進むボタン等を精密トリガーに割り当てた場合はキーコンボ機能と排他
- [ ] 必須4: 精密モードの移動量スケールをUIでコントロール可能（10%〜100% スライダー、デフォルト30%）。有効時はポインタ移動deltaをスケール（加速カーブは触らない）
- [ ] 必須5: 設定UI（MenuBarExtra常駐 + Settingsウィンドウ、HUD色変化で精密ON表示）で各割り当てと精密モード有効/無効・スケール・トリガー・モード種別を変更・保存・再起動後も保持
- [ ] 必須6: BSTBB700のBluetooth接続で動作確認。DiscoveryログモードでButton/Consumer/Keyboardのどれで届くかを判別し、他マウスへの誤爆をフィルタ or 明記（MVPはグローバル減速である旨をUIで明記、将来デバイス限定フィルタを追加）
- [ ] 任意1: 自動起動 (SMAppService)、プロファイル切替、アプリ別除外
- [ ] 任意2: 垂直スクロール素通し、水平チルトのみカスタムのトグルオプション
- [ ] 任意3: Homebrew cask配布、水平スクロール速度拡張

## 制約

- 技術スタック: Swift + SwiftUI + AppKit, CGEventTap / IOHIDManager / CGEventPost, Xcodeプロジェクト（SPM可）
- 期限: 未定（MVP検証 → 段階拡張）
- 参照: Karabiner-Elements, SteerMouse, LinearMouse 参照。TCCはAppleドキュメント準拠
- 配布: Sandbox外（Input Monitoring必須）。署名なし対応: ad-hoc署名 + 手動Gatekeeper回避（右クリック開く/xattr -cr）+ 将来Developer ID取得時に公証。App Store不可は確定。配布はDMG/zip直配布 or Homebrew cask（任意）
- UI: MenuBarExtra常駐 + Settings、HUDインジケータ、TCCガイド同梱

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| イベント取得方式 | CGEventTap主力 + IOHID列挙補助（ハイブリッド相関50ms窓） | ドライバ/kext/DriverKit | kextはTahoe不可、DriverKitは過剰。CGEventTapがKarabiner実績あり最短 |
| 精密モード実装 | CGEvent mouseMoved deltaスケール（10-100%スライダー、デフォルト30%） | システムのポインタ速度書き換え | システム設定は副作用大、deltaスケールが隔離性高い・即時反映 |
| 精密トリガー | 単一トリガー選択式（トグル or ホールド択一）+ キーボード未使用キー or マウス（進む/チルト右）から1つ | トグル/ホールド同時常時両立 | 根本さん要望「どちらか」で両立は排他。同一キー長押し判定は誤爆するため択一がシンプル |
| 対象デバイス絞り込み | BSTBB700専用だがVID/PIDはDiscoveryで自動特定、フィルタは設定でON/OFF切替 | 固定VID/PID決め打ち | 新型でVID/PID未確定のためDiscoveryログで特定しつつ汎用フォールバックを残す |
| 進む戻る扱い | 未割り当ては素通し、割り当て時は横取り消費。ダメなら再検討 | 常時横取り | ブラウザ機能を温存しつつカスタムも両立。Hermes指摘の相関で誤爆低減 |
| UI形態 | MenuBarExtra常駐+Settingsウィンドウ+HUD色変化 | Dock常駐通常アプリ | 追従性と常駐性を両立、TCCガイドも出しやすい |
| 配布/署名 | ad-hoc署名でMVP、Gatekeeperは手動回避（xattr -cr/右クリック開く） | 即時Developer ID公証 | 署名なしのため無料で動かす最短。Homebrew caskは任意で将来対応 |
| チルト割り当て | MVPはキーコンボのみ、将来拡張余地を構造に残す | Mission Control/音量等をMVPに含める | 本質的シンプルさ優先、将来プロトコル拡張で追加可能 |

## 迷い要件 — 回答済み（2026-08-29 Chat）

1. BSTBB700（BUFFALO新型、根本さん企画、未発売）1台専用で確定
2. 進む戻るは未割り当て素通し/割り当て時横取りで確定。失敗時は再検討
3. チルト/中央はキーコンボのみで確定。将来拡張余地は構造に残す
4. 精密トリガーは未使用キー or マウス（進む/チルト右）から1つ、モードはトグル or ホールド択一で確定。両方同時は不要
5. 減速30%で確定、加速は触らずスライダーで調整
6. UIはMenuBarExtra常駐+Settings+HUDで確定
7. 署名なし・無料配布希望で確定 → ad-hoc署名+手動回避でMVP
8. 実機あり接続可で確定 → DiscoveryログでUsage特定へ
