# brief.md — グラディウス式 T武装拡張

## 課題

現行のT-POWER（3ライン1点/4ライン2点でT変換）を、Tを使いすぎるという指摘を受け、グラディウスのバリア待機のような2段階武装へ進化させる。ゲージをためて武装し、武装したTを保持しつつゲージを再びためることで最硬の防御を実現する。

## 前提条件

- [x] ベースは `docs/tetris/index.html` 1149行版（T-POWER直接変換版を上書き進化）
- [x] たまり方は同じ（3ライン1点、4ライン2点、1-2ライン0、上限3）を維持
- [x] 単一HTML / file:// / localStorage 制約は維持

## 成功基準

- [x] 必須1: ゲージ蓄積 — 3ライン1点、4ライン2点、1-2ライン0で powerGauge 0→3 へ蓄積。ただし2点たまった状態からは3ラインでも4ラインでも必ず3に到達する（上限でクリップ、2+1=3、2+2=3）
- [x] 必須2: 武装（ストック） — powerGaugeが3の時に G/W を押すと、Tを1個ストックできる。ストックすると powerGaugeは0に戻る。ストックは最大1個まで。武装直後300msは次のG/Wを無効化し、連打による武装→即発射の誤爆を防ぐ
- [x] 必須3: 発射 — ストックを1個持っている時に G/W を押すと、現落下ブロックがTに変換され、ストックは0になる。T変換はSRS壁キックを適用し、失敗すれば変換せずストックも消費しない。失敗時は200msのクールダウンと揺れ演出のみで無限試行を防ぐ。ストックがない状態でG/Wを押しても何も起きない
- [x] 必須4: バースト — powerGaugeが3の状態（ストック0/1いずれも）で、武装せずにさらに3ラインまたは4ラインを消してしまうと、バーストして powerGaugeは0に戻る（ストックは保持される。例: ストック1+ゲージ3でバーストするとゲージのみ0に戻りストック1は残る）。演出として「BURST!」を1秒表示し、ゲージを赤く点滅させる
- [x] 必須5: ストック中の再蓄積 — ストック（Tを1個武装）を保持している間も、powerGaugeは0から再びたまり始める。ストック1 + ゲージ3が最硬の防御状態となり、1-2ライン消しで耐える（1-2ラインは加算0なので溢れずに維持できる）ことが可能であること
- [x] 必須6: ゲージUI — SIDEのT-POWERカードに、ゲージ3マス（空は#1a1f3a / 満は#a855f7）とストックTアイコン（武装時は点灯・未武装時は消灯）が明確に区別して表示されること。ゲージ3は武装可能で金色に発光、ストック1はTアイコンが紫に発光する。バースト時はゲージが赤く点滅すること
- [x] 必須7: セーブ/ロード対応 — powerGauge と tStock（0/1）が `phronisis_tetris_save_v1` に含めて保存・復元されること
- [x] 必須8: リグレッションなし — 既存のスコア/レベル/T-Spin/オートセーブ/カウントダウン/3列レイアウト等が引き続きPASSすること
- [ ] 任意1: 武装時の効果音/発光の強化
- [ ] 任意2: バースト時のペナルティ演出の強化

## 制約

- 技術スタック: 単一HTML / IIFE / Canvas 2D / localStorage のみ
- 配置: `docs/tetris/index.html` を上書き。行数は1150-1300行を目安とする
- キー体系: T武装/発射は G/W 両対応で、1回目のG/Wで武装、2回目のG/Wで発射。ホールドCとは別
- 品質: `scripts/code_health_check.py --no-color` 5/5 PASS 維持

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| たまり方 | 3で1、4で2維持、2→3はどちらでも3へ | たまり方変更 | ユーザ提案の3で1/4で2は熱いままなので維持。2→3の特別扱いは上限クリップで自然に実現できる |
| 武装の分離 | 2段階（ゲージ3→G/Wでストック→G/Wで発射） | 1段階（ゲージ3→即T変換） | Tを使いすぎる問題を、ゲージから直接発射するのではなく一旦ストックを経由することで使用頻度を下げ、武装のタイミングで戦略性を生む |
| ストック中の蓄積 | ストック中もゲージは0から再蓄積可 | ストック中は蓄積停止 | グラディウスのバリア待機のように、武装しつつゲージを再び3までためることで最硬防御を実現するため。1-2ラインで耐える運用が可能になる |
| バースト | 3の状態（ストック0/1いずれも）で放置して3/4を消すとゲージのみ0に戻る（ストックは保持、BURST!と赤点滅） | 溢れ消失のみ/ストックも消失 | 満タン放置の罰を明確化しつつ、最硬防御（ストック1+ゲージ3）ではゲージのみを剥がしてストックを残すことで理不尽な二重罰を避ける |
| キー | G/Wの2回押しで武装→発射、武装直後300msロック、失敗時200msクールダウン+揺れ | 別キーで武装/発射を分離 | 同一キー2回押しで覚えやすく、ロック/クールダウンで誤爆と無限試行を防ぐ。ホールドCとは別枠で競合しない |
| UI区別 | ゲージ3マスは紫# a855f7、ストックTアイコンは別枠で金/紫に発光 | 文字のみ/色のみ | ゲージ3+ストック0とゲージ0+ストック1を一瞬で区別できるよう、3マスは横並び、ストックはTアイコンで縦に分離し発光色を変える |
