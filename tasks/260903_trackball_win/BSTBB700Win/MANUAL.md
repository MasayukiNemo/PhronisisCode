# BSTBB700Win マニュアル

BUFFALO BSTBB700 トラックボールを Windows 11 でカスタマイズする常駐アプリの取扱説明書。
対応: Windows 11 64bit / BSTBB700（Bluetooth接続）/ BSTBB700Win 0.2.5

## 目次

1. 起動する
2. 最初にやること（Discoveryで確認）

4. 精密モードを使う
5. 一般タブ（自動起動など）
6. トレイとHUD

## 1. 起動する

1. BSTBB700 を Bluetooth で PC に接続しておく
2. dist/BSTBB700Win.exe をダブルクリックする
3. 初回は SmartScreen 警告が出ることがある。「詳細情報」→「実行」を押す
4. ウイルス対策ソフトに止められたら除外設定を行う（低レベルフック＋キー送信のため誤検知される場合がある）
5. 設定ウィンドウが開く。タブは「割り当て」「精密モード」「Discovery」「一般」の4つ

## 2. 最初にやること（Discoveryで確認）

機体差（進む戻りの逆転・チルト符号の逆転）を吸収するため、先に確認する。

1. 「Discovery」タブを開く
2. 進む・戻る・チルト左右・中央押しを押す。「更新」を押すとログが出る
   - 進む/戻る → mouse kind=forward/back down/up
   - チルト → mouse kind=tiltLeft/tiltRight down
   - 中央押し → mouse kind=center down/up
3. 進むと戻りが逆に表示される場合 → 「割り当て」タブの「進む/戻るを入れ替え」をON
4. チルト左右が逆に表示される場合 → 「割り当て」タブの「チルト左右を反転」をON
5. ログが増えたら「クリア」で消せる

## 3. ボタンにキーを割り当てる

「割り当て」タブ。各行は「戻る」「進む」「中央押し」「チルト左」「チルト右」。

- 未割り当ては素通し（ブラウザの進む/戻る等はそのまま動く）
- 割り当てると横取りしてキー送信する
- 精密モードのトリガーに使っているボタンは割当不可になり、赤字で警告が出る

割当方法は3つ。

### キャプチャ（押したキーをそのまま登録）

1. 行の「キャプチャ」を押す
2. 小窓が出たら割り当てたいキーを押す（Ctrl+C などの同時押し可）
3. Esc を押すか「取消」を押すと中止する
4. 注意: Esc 自体はキャプチャで記録できない。Esc を割り当てたい場合はビルダーを使う

### ビルダー（リストから組み立て）

1. 行の「組み立て」を押すと入力欄が開く
2. 修飾（Ctrl/Shift/Alt/Win）にチェックし、キーを一覧から選んで「反映」を押す
3. 「プリセット」から選ぶと定番が一発で入る。一覧は次の通り
   - 未割り当て（選ぶとクリア扱い）
   - 戻る (Alt+Left)、進む (Alt+Right)
   - コピー、ペースト、カット、取り消し、やり直し、全選択、検索
   - タブ次 (Ctrl+Tab)、タブ前 (Ctrl+Shift+Tab)
   - F13、F14、F15
4. 「クリア」で未割り当てに戻す

## 4. 精密モードを使う

カーソル速度を一時的に落とすモード。「精密モード」タブで設定する。

- 「精密モードを有効化」にチェック
- トリガーを1つ選ぶ。表示は平易名（F13キー・進むボタン・戻るボタン・チルト左など）。戻る・進む・中央はホールド可、チルトはトグルのみ
- 「切替時にHUD表示する」のチェックでHUDの表示・非表示を切り替え（トレイと状態表示は常時）
- 「精密ON中に拡大鏡を表示する」でカーソル右斜め上に追従ズーム。倍率は2・3・4倍から選択、大きさはスライダーで調整。精密OFFで消える
- customKey を使う場合: VK番号を入力して「custom VK適用」か「キャプチャで設定」。キャプチャならトリガーも自動で customKey になる
- モードはトグル（押すたびON/OFF）かホールド（押している間のみ）の択一
  - チルト系トリガーはホールド不可（離した検出がないため）。トグルのみ
- スケールはスライダー・数値入力・プリセット（10/25/50/100%）で10〜100%。初期25%。数字が小さいほど遅い
- 「ON/OFF切替」ボタンで手動切替も可。状態は色と文字で表示される
- 注意: MVPはグローバル減速。全マウスとタッチパッドが減速する。終了時は元の速度に自動復元される

## 5. 一般タブ（自動起動など）

- 自動起動: チェックでWindows起動時に自動起動（レジストリRunに登録）。exe版のみ有効。開発実行（python app.py）中は登録不可と表示される
- 垂直ホイールは素通し。カスタム対象は水平チルトのみ
- AV/SmartScreen の案内を表示
- 「設定フォルダを開く」で保存先を開く
- 「設定リセット」で全設定を初期化する。押すと確認が出る

## 6. トレイとHUD

- 起動中はタスクトレイに常駐する。左クリックで設定画面表示、右クリックメニューで設定・精密切替・終了
- 精密ON/OFFでトレイアイコンとツールチップが変わる
- 精密を切り替えると画面右上にHUDが出て状態を知らせる（約1.5秒で消える）
- トレイ起動に失敗した場合は窓常駐で継続する

## 7. 設定の保存場所とリセット

- 保存先: %APPDATA%/BSTBB700/settings.json（自動保存、再起動後も保持）
- リセット: 一般タブの「設定リセット」。確認に答えると初期化される

## 7. 終了する・アンインストールする

- 終了: ウィンドウを閉じるかトレイメニューの終了。終了時はマウス速度を元に戻す
- 自動起動の解除: 一般タブのチェックを外す
- アンインストール: exe を削除し、%APPDATA%/BSTBB700 を削除する

## 8. 困ったときは

- フック開始に失敗と出る: ウイルス対策の除外設定を見直し、再起動する。設定変更だけはできる
- フック停止中と出る: Escを2秒以内に5回押すか無効化フラグで停止した状態。Discoveryタブの状態表示を見て「フック再開」を押す
- 無効化フラグありと出る: %TEMP%/bstbb700_disable ファイルが残っている。消して「フック再開」を押す
- 割り当てたのに効かない: 赤い警告（精密トリガーと排他）が出ていないか見る。Discoveryでボタン名が想定通りか見る
- 進む戻り・チルトが逆: 割り当てタブの入れ替え・反転を見直す（手順2）
- キャプチャで変なキーが入る: 修飾キーは同時押しで合成される。単独押しのつもりが長押しだと修飾つきになることがある。取り直すかビルダーで直す
- マウス速度が戻らない: アプリを再起動して終了する。起動時に復元される
- SmartScreen/ウイルス対策: 手順1の通り詳細情報から実行・除外設定
- それでも直らない: settings.json を削除して初期状態に戻し、Discoveryからやり直す
- デバッグログを取りたい: Discoveryタブのチェックを入れると %TEMP%/bstbb700_debug.log に記録される
