# brief.md — YouTube 文字起こし（バッファロー決算説明会）

## 課題

モコの依頼（2026-11-19）。YouTube 動画 https://youtu.be/S7EdrwdbYzQ の字幕を取得し、読みやすい文字起こしテキスト1本にして Box に納品する。要約・改変はしない。固有名詞以外の自動字幕の誤変換は残し、冒頭に注記する。

## 成功基準

- [x] 必須: 字幕の取得（手動優先、無ければ自動 ja-orig）
- [x] 必須: タイムスタンプ除去・重複表示の除去・段落入れ（内容は不変）
- [x] 必須: 冒頭の注記（字幕種別・整形条件・誤変換の留保）
- [x] 必須: Box moko-code への配置と、ファイル名・置き場所・字幕種別・タイトル・長さの報告

## 制約

- 要約・改変をしない
- 明らかな固有名詞の誤り以外は直さない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 字幕 | 自動 ja-orig | en / ja（翻訳） | 元言語。翻訳を挟むと内容が変わる |
| VTT→平文 | 各キューの最終行を、直前の文との重なりで差し引いて連結 | 全行を連結 | 自動字幕は前の行を繰り返すため、全行連結では3重になる（実測） |
| 改行 | 文末で段落、300字超は読点で折る | 1行に全部 | 読み物としての可読性。内容は変えない |
| ファイル名 | 日本語名（python の subprocess 経由で rclone） | PowerShell から直接 | PowerShell 経由だと Box 上で文字化けする（実測） |
