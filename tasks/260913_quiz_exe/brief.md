# brief.md — クイズゲームexe化＋選択式（テーマ・設問数・難易度4段階）

## 課題

quiz_game.pyをWindows exe化し、起動時にテーマ・設問数・難易度（4段階、現行は下から2番目相当）を選べるゲームにする

## 前提条件

- [ ] PyInstaller 6.22.2利用（ビルド時のみ。実行時追加依存なし）
- [ ] dist/ build/ *.specはgitignore対象のためexeはコミットしない（ローカル成果物）
- [ ] conduct準拠（quota事前確認・7%以下停止）は維持

## 成功基準

- [ ] 必須: dist/quiz_game.exeが対話開始しN問出題する
- [ ] 必須: テーマ・設問数・難易度4段階を選択できる
- [ ] 必須: 難易度2が現行レベル相当である
- [ ] 必須: exeからagy ask/quotaが通る（凍結時パス解決対応）
- [ ] 必須: agy不調時は明示エラー終了

## 制約

- 実行時追加依存なし（標準ライブラリ＋agyバイナリ）
- 前回修正（EOF中止・Ctrl+C・再入力・救済）を維持

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 凍結対応 | モジュール取込（import agy_query） | サブプロセス維持 | frozen時sys.executableがexe自身になりscripts相対が崩れる。取込で解消 |
| 難易度 | プロンプト指示4段階 | モデル切替 | High/Mediumはquota直結で課金設計を汚す。言葉で調整する |
| exe扱い | dist配置・未コミット | コミット | gitignore設計に従う。バイナリは追従負債になる |
| メニュー | 全項目デフォルト付き（空Enter進行） | 毎回必須入力 | 開始前の手間を増やさない。テーマ空=おまかせ・数5・難易度2 |
| 難易度定義 | 4段階テーブルをプロンプトに埋込 | 言葉だけ | 1おてがる/2ふつう現行/3ひねり応用/4専門細部を構造化 |
