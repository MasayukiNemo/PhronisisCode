# brief.md — 日本語訳の数値・固有名詞照合

## 課題

モコの依頼（2026-11-20）。`moko-code/yt-extract-20261120/transcript_ja.txt`（日本語全文訳）の数値と固有名詞を、同じフォルダの `transcript_en.txt` と突き合わせる。対象は数値と固有名詞のみ。読みやすさ・文体は見ない。結果は食い違いの一覧だけ。訳文の書き換えはしない。

## 成功基準

- [x] 必須: 段落対応（25対25）での数値の比較
- [x] 必須: 固有名詞の対応確認
- [x] 必須: 食い違いの一覧、または「一致」の報告
- [x] 必須: 訳文を書き換えない

## 制約

- 読みやすさ・文体は評価しない（モコの領分）
- 直すかどうかはモコが決める。こちらは差分を出すだけ

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 数値の比較 | 段落ごとの多重集合 | 全文の合計だけ | 段落対応が取れているので、位置まで見られる |
| 語数字 | 数字に開いて数える | 数字だけで比較 | 英語本文に数字が1つも無い（すべて語）ため |
| 固有名詞 | 英語の大文字連鎖から候補を出し、日本語の対応を目視 | 全文の機械照合 | カタカナ表記の揺れで誤検出する |
| 差分の扱い | 「原文側の重複」は注記に分ける | 食い違いとして扱う | 訳の誤りではない。カウント差の説明として残す |
