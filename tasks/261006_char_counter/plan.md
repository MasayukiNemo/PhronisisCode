# plan.md — 1枚HTML 文字数カウンタ

## アーキテクチャ

単一ファイル `tasks/261006_char_counter/char_counter.html`。構成は textarea 1つ + 計測結果グリッド。

- DOM: 入力 `textarea`、結果6項目（改行含む / 改行含まない / 行数 / 空白除外 / 全角 / 半角）
- 更新: `input` イベントで `count()` を呼び、`textContent` のみ更新（innerHTML不使用でXSS面なし）
- 状態: 持たない。入力文字列から毎回算出する純関数

計測定義（count(text)）:

- 文字数（改行含む）: `Array.from(text).length`（コードポイント単位）
- 文字数（改行含まない）: CR/LF を除いたコードポイント数
- 行数: `text.split(/\r\n|\r|\n/).length`。空文字は0
- 空白除外文字数: `/\s/` に一致する文字（半角/全角スペース・タブ・改行）を除いたコードポイント数
- 全角/半角: 各コードポイントを東アジア全角レンジ（かな・漢字・全角記号・全角英数・絵文字等）で判定。半角=それ以外（ASCII・半角カナ・改行含む）。全角+半角=改行含む文字数
