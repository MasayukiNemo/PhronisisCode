# brief.md — タスク定義

## 課題

テキストエリアへの入力をリアルタイムに計測する文字数カウンタを、単一HTMLファイルで提供する。ネットワーク不要・外部依存なしで、どの端末でも開くだけで動く手元の道具とする。

## 前提条件

- [x] 成果物はHTMLファイル1枚（CSS/JSインライン）。外部CDN・フォント・画像なし
- [x] オフライン（file://）で動作する
- [x] 計測はクライアントサイドのみ。入力テキストを外部送信しない
- [ ] 実行環境はモダンブラウザ（Chrome/Edge/Firefox/Safari）
- [ ] 対象は日本語を含むテキスト

## 成功基準

- [ ] 必須: 単一HTML・外部依存なし・file://で動作
- [ ] 必須: 文字数（改行含む）をリアルタイム表示
- [ ] 必須: 文字数（改行含まない）をリアルタイム表示
- [ ] 必須: 行数をリアルタイム表示
- [ ] 必須: 空白除外文字数をリアルタイム表示
- [ ] 必須: 全角/半角の内訳をリアルタイム表示
- [ ] 任意: 大きめテキストでも引っかからない応答

## 制約

- 技術スタック: HTML + インラインCSS + Vanilla JS（フレームワークなし）
- 期限: なし
- 参照: なし（新規）

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| 文字数の単位 | コードポイント（Array.from） | UTF-16長（.length） | 絵文字などサロゲートペアを1文字と数え、見た目と一致させるため |
| 全角/半角の定義 | 東アジア全角レンジで判定、合計=総文字数 | 見た目の幅で曖昧判定 | 検算可能な決定的ルールにするため |
| 改行の扱い | 半角側に計上 | 内訳から除外 | 全角+半角=総文字数の等式を保つため |
| 空白除外の範囲 | /\s/（半角/全角スペース・タブ・改行） | 半角スペースのみ | 「空白」の語から全角スペースも除外するのが自然なため |
| 空入力の行数 | 0行 | 1行 | 入力ゼロは行ゼロと直感に合うため |
| 更新方式 | 入力から毎回算出する純関数 | 差分カウント | 状態を持たずバグを入れないため |
| 記号の数え方 | コードポイントのまま | Segmenterで書記素クラスタ | Yunaの「絵文字=1文字」指摘に対し、Hayatoが要件外かつ環境依存の過剰設計と指摘。単一ファイルの決定性を優先 |
| 付加機能 | カウンタのみ | 自動保存・コピー | 要件外。Hayatoが「要件の捏造」と指摘。file://ではclipboard APIも不安定 |
| IME未確定 | inputの都度カウント | 確定後のみ | リアルタイム要件に素直。composition制御は足さない |
| 巨大テキスト | rAFで更新を間引く | 無対策／Web Worker | 過剰にならない最小の緩和。全走査はO(n)のまま |
| 招集判断 | 神は招集せず、Yuna/Hayatoのトライアングルのみ | Gaia/Daedalus/Metis等 | 設計案は単一・1ファイル・実装は小規模。呼ばなかった理由をここに残す |
