# brief.md — クイズGUI版（tkinter・マウス操作）

## 課題

CLI版の反省（GUI選択肢を出さなかった）を受け、マウスで遊べるGUI版を作る。tkinter標準ライブラリのみ、exe化して配布する

## 前提条件

- [ ] 出題ロジックはquiz_game.pyの関数を再利用する（二重実装しない）
- [ ] 実行時追加依存なし（tkinterは標準ライブラリ）
- [ ] conduct準拠（quota事前確認・7%以下停止）は維持

## 成功基準

- [ ] 必須: マウス主導で完走できる（テーマ入力のみキーボード。完走=設定→開始→回答→次へ→結果→もう一度）
- [ ] 必須: 生成中も固まらない（スレッド化＋二重押下防止＋進捗表示）
- [ ] 必須: dist/quiz_gui.exeが起動し設定画面を表示する
- [ ] 必須: agy不調時は画面に明示エラー
- [ ] 必須: クリック完走は根本さんが実機確認する（本タスクの検証は起動まで）

## 制約

- --windowedビルド（コンソールなし）
- CLI版の出題品質（難易度表・救済・検証）を落とさない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| GUI手段 | tkinter | ブラウザ/web | 標準libのみでexe同梱可。サーバ不要 |
| ロジック | quiz_game関数をimport再利用 | GUI内に複写 | 二重実装はdriftの元。単一正本を維持 |
| 解説の間 | 二拍子（解説を見る→次へ） | 一画面同時表示 | 風情。解説を味わう一拍を作る |
| 偽選択肢 | 設計指示（同類・等長・すべて系禁止） | おまかせ | におう選択肢を構造で潰す。正解より難しい部分を仕様化 |
| 独断修正 | 事後トライアングル＋Metisで検証 | そのまま確定 | 越権の指摘を受け停止。黒窓抑止・一拍子・意匠をYuna/Hayato/Metisにかけた |
| 寸評 | tier別複数文型＋結果埋込 | 固定文3種 | いつも同じは手抜き。テーマ・難易度・点数を文に織り込む |
| 再戦 | 結果画面に別セット＋難易度変更 | 設定に戻ってやり直し | 同じテーマで潜り直せる。テーマ保持・難易度選択を結果画面に置く |
| 長文 | 大窓＋折返し＋生成側字数目安 | スクロール | スクロールは面倒。窓720化と200/60/300字目安で収める |
| 生成中表示 | テーマ・問数・難易度を表示 | 固定文 | 何を作っているか見せる親切さ |
| 保存 | 結果画面にテキスト保存 | 消し捨て | 出題・回答・正解・解説を残す。もったいないを潰す |
| マニア字数 | 難易度別上限（マニア500/120/600） | 一律制限 | 一律はマニアの質を殺ぐ。正確さ優先も明記 |
| 寸評重複 | 呼出側の二重表示を除去 | 放置 | テンプレ内蔵点数と二重になっていた |
| 言い訳禁止 | 情報少テーマでもJSONのみ | 現状維持 | 未帰還の一因（前置き膨張）潰し。実証は実ask許可後に |
| 選択肢切れ | tk.Button折返し化 | ttkのまま | ttk.Buttonはwrapしない。disabled化もconfigureに修正 |
| マニア上限2 | 300/70/400に締め直し | 350維持 | 430秒未帰還を受け上限過大と判断。回答10%削減 |
| 再試行可視化 | CLI表示＋GUI状態表示 | 無言リトライ | 390秒死→無言再試行が5分未帰還の正体と推定 |
| 逐次取得 | 撤回（まとめ取りに戻す） | 1問ずつ | quota約5倍は却下。1ask＋経過秒＋問数連動timeoutで耐える |
| 検証方針 | stubsのみ・実ask停止 | 実実行併用 | 本線配慮でクォータ消費を止める。以降stubs＋起動検証のみ |
| 生成待ち | スレッド＋afterポーリング | 同期呼出 | 固まるUIはユカイじゃない検出に触れる |
