# brief.md — クイズGUI版（tkinter・マウス操作）

## 課題

CLI版の反省（GUI選択肢を出さなかった）を受け、マウスで遊べるGUI版を作る。tkinter標準ライブラリのみ、exe化して配布する

## 前提条件

- [ ] 出題ロジックはquiz_game.pyの関数を再利用する（二重実装しない）
- [ ] 実行時追加依存なし（tkinterは標準ライブラリ）
- [ ] conduct準拠（quota事前確認・7%以下停止）は維持

## 成功基準

- [ ] 必須: マウス主導で完走できる（テーマ入力のみキーボード。完走=設定→開始→回答→次へ→結果→もう一度）
- [ ] 必須: 生成中も固まらない（スレッド化＋二重押下防止＋進捗表示）
- [ ] 必須: dist/quiz_gui.exeが起動し設定画面を表示する
- [ ] 必須: agy不調時は画面に明示エラー
- [ ] 必須: クリック完走は根本さんが実機確認する（本タスクの検証は起動まで）

## 制約

- --windowedビルド（コンソールなし）
- CLI版の出題品質（難易度表・救済・検証）を落とさない

## 判断の軌跡（実行中に記録）

| 論点 | 選んだ案 | 潰した案 | 理由 |
|------|---------|---------|------|
| GUI手段 | tkinter | ブラウザ/web | 標準libのみでexe同梱可。サーバ不要 |
| ロジック | quiz_game関数をimport再利用 | GUI内に複写 | 二重実装はdriftの元。単一正本を維持 |
| 解説の間 | 二拍子（解説を見る→次へ） | 一画面同時表示 | 風情。解説を味わう一拍を作る |
| 生成待ち | スレッド＋afterポーリング | 同期呼出 | 固まるUIはユカイじゃない検出に触れる |
